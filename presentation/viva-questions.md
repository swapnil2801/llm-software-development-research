# Viva Questions and Short Answers

1. **What is an LLM?** A neural language model trained on large text/code corpora to predict and generate sequences.
2. **Why are LLMs useful in software development?** They can translate natural-language intent into drafts, explanations, tests, documentation, and transformations.
3. **Do LLMs understand code like a human engineer?** They model patterns and context; they do not guarantee semantic understanding or correctness.
4. **What is the difference between assistance and automation?** Assistance supports a human decision; automation executes a task with limited intervention. Software work often needs a hybrid approach.
5. **What did the Copilot experiment show?** In a controlled JavaScript HTTP-server task, the treatment group completed the task 55.8% faster; this result should not be generalized to every project.
6. **What is hallucination?** A plausible but false output, such as incorrect APIs, fabricated explanations, or nonexistent packages.
7. **Why is testing still necessary?** Generated code can compile while violating requirements, security properties, or edge cases.
8. **What are the main security concerns?** Vulnerable code, secret leakage, prompt injection, unsafe dependencies, and supply-chain attacks.
9. **Will LLMs replace developers?** Evidence supports task-level assistance; requirements judgment, architecture, accountability, and verification remain essential.
10. **What is the main conclusion?** Adoption should be evidence-driven, risk-aware, and supervised by qualified engineers.
